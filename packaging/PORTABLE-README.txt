RS-StatChem — Windows portable

1. Extract this zip anywhere (Documents, Desktop or a USB drive).
2. Open the RS-StatChem folder and run RS-StatChem.exe. No installation is needed.

Settings are stored in the "UserData" folder next to RS-StatChem.exe, so the whole folder can be
moved to another computer. If Windows SmartScreen warns about an unknown publisher, choose
"More info" -> "Run anyway" (the app is not code-signed).

Delete the folder to remove the app completely.
