RS-StatChem — Windows portable

1. Extract this zip anywhere (Documents, Desktop or a USB drive).
2. Open the RS-StatChem folder and run RS-StatChem.exe. No installation is needed.

Settings are stored in the "UserData" folder next to RS-StatChem.exe, so the whole folder can be
moved to another computer. If Windows SmartScreen warns about an unknown publisher, choose
"More info" -> "Run anyway" (the app is not code-signed).

If Windows 11 instead shows "Smart App Control blocked an app that may be unsafe" with only an
OK button, there is no "Run anyway": the app opens only after Smart App Control is turned off
(Windows Security -> App & browser control -> Smart App Control settings -> Off; needs an
administrator account). Do this only on your own computer. On Windows 11 without the April 2026
update or later, Smart App Control cannot be turned on again without reinstalling Windows.
The user guide (RS-StatChem-User-Guide.pdf on the download page) has the steps in Indonesian.

Delete the folder to remove the app completely.
